IP Nurse Leader Rounding Overview

This dashboard reflects CipherHealth's goal to round on a certain percentage of patients at least once per day per unit.

Please Note: The default date filter is set to previous day, however you can adjust this to reflect a period of time. It is critical that rounds are documented and submitted near real-time to ensure that all rounds are reported on correctly.

To see data for the care setting you oversee, use the filters up top.
