# Beyond Health — Custom Outreach Demo Pack

Conversational AI SMS demos for **Beyond Health** (Albuquerque DPC), styled like Cipher TCM / COPD / CHF outreach: bot asks in plain language, patient replies casually (no numbered menus, no em dashes).

## Quick start

1. Open the SMS Demo Builder (`index.html`).
2. Confirm the dropdown still includes **TCM**, **Care Gaps**, **COPD**, and **CHF** (restored).
3. Select **Beyond Health - GLP-1 Program Continuity**.
4. Patient/Hospital auto-set to Maria / Beyond Health.
5. Present mode → advance the natural-language risk path.
6. Use `02-OPEN-CASES-SEED-LIST.md` for the staff / Open Cases moment.
7. Follow `03-DEMO-RUN-OF-SHOW.md` for timing.
