# Beyond Health — Custom Outreach Demo Pack

Assets for the **Beyond Health** (Albuquerque DPC) demo: GLP-1 / weight program continuity as the hero use case, plus wellness care-gap and pre-visit prep vignettes.

## Quick start

1. Open the SMS Demo Builder (`index.html`).
2. From the template dropdown, choose **Beyond Health — GLP-1 Program Continuity**.
3. Confirm settings: Patient = `Maria`, Hospital = `Beyond Health` (auto-applied on template switch).
4. Present mode → advance the risk path (side effect → missed nutrition → callback).
5. Use `02-OPEN-CASES-SEED-LIST.md` for the staff / Open Cases moment.
6. Follow `03-DEMO-RUN-OF-SHOW.md` for timing and talk tracks.
